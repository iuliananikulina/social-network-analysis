# Оценка критической массы и ценности социальной сети

## О задаче

Компания «ГородСоцСеть» запускает социальную сеть для жителей города с населением 1 млн человек. Необходимо оценить:
- Критическую массу — минимальное число пользователей, при котором сеть становится самоподдерживающейся.
- Время достижения критической массы.
- Ценность сети по закону Мэткалфа.
- NPV проекта за 36 месяцев.
- Стратегические рекомендации.

## Ключевые понятия

- **Закон Мэткалфа:** ценность сети растёт как квадрат числа пользователей (V = k × N²).
- **Критическая масса:** число пользователей, при котором доход покрывает все затраты.
- **Сетевой эффект:** после достижения критической массы рост ускоряется с 3% до 15% в месяц.

## Исходные данные

| Параметр | Значение |
|---|---|
| Потенциал рынка (M) | 1 000 000 чел. |
| Начальное число пользователей (N₀) | 5 000 чел. |
| Рост до критической массы | 3% в месяц |
| Рост после критической массы | 15% в месяц |
| Коэффициент ценности (k) | 0.005 руб./польз.² |
| Фиксированные затраты | 2 000 000 руб./мес. |
| CAC | 500 руб. |
| ARPU | 15 руб./мес. |
| Горизонт | 36 месяцев |
| Ставка дисконтирования | 1% в месяц |

## Ключевые результаты

| Показатель | Значение |
|---|---|
| Критическая масса | **133 333 чел.** (13.3% рынка) |
| Число пользователей через 36 мес. (при 3%) | 14 491 чел. (11% цели) |
| Месяцев до критической массы при 3% | ≈ 111 мес. (9.3 года) |
| **NPV проекта (базовый сценарий)** | **−62 024 621 руб.** ❌ |
| Безубыточный ARPU | ≈ 245.48 руб./польз./мес. (в 16.4 раза выше текущего) |

## Главный вывод

**Проект в текущих параметрах убыточен.** NPV = −62 млн руб. — компания тратит больше, чем зарабатывает. Ускорение роста без изменения экономики только **усиливает убытки** («покупка убыточного роста»).

**Успех возможен только при комплексной смене стратегии:**
1. Смена бизнес-модели монетизации (премиум, реклама, B2B).
2. Снижение CAC (виральные механики, партнёрства).
3. Оптимизация фиксированных затрат (облако, минимальная команда).
4. Фокус на узком сегменте (район, сообщество).
5. Реалистичные KPI.
